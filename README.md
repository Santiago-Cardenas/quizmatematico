# quizmatematico

 
Prompt inicial:
"Genera un script en Bash que implemente un quiz matemático. Debe tener un menú con opciones para suma (0-100), resta (0-100, siempre positivo), multiplicación (A:1-100, B:1-10) y división (A:1-20, B:1-10, asegurando resultado entero mediante A=A*B). Cada pregunta debe dar 3 oportunidades al usuario. Si acierta, felicitar; si falla 3 veces, mostrar la respuesta correcta. El menú debe repetirse hasta que se elija la opción 9."


Prompt de refinamiento:
"Optimiza el código utilizando una función para la lógica de los intentos, de modo que no se repita el código de validación en cada operación matemática, y asegúrate de que el intercambio de variables en la resta use una variable temporal."
